## 1. Design Read (per design-taste-frontend Section 0.B)

**One-line read:**

> Reading this as: **creative education center for adult self-learners in Vasai-Virar**, with a **quiet-studio language**, leaning toward **DM Serif Display (display) + Inter (body) on warm white, accent in deep ink navy**.

**Why this read:**

- **Industry:** TGC is an education center with at least one structured 6-month drawing course. That's textbook coaching, not generic creative agency. The coach template + quote-builder CRO engine is the right routing.
- **ICP:** The founder's Instagram bio says "A space for Mind, Art, Music and Expression. Learn, create and transform with us." That targets adults who want a serious practice, not hobbyist weekend drop-ins. Quiet-studio tone fits this audience; flashy agency tone would feel wrong for someone choosing a 6-month commitment.
- **Vibe:** Quiet studio. Not gallery-poster. Not Apple-product. The owner bio talks about "premium, 6-month immersive journey" — that signals care, structure, considered. We mirror that with restrained motion and a serif display that earns its place on the word "Collective".
- **Design system:** Native CSS + Google Fonts (DM Serif Display + Inter). No framework, no React, no Tailwind. This site ships as static HTML the owner can edit in any text editor. The ₹24,999 deliverable is hand-written, not generated by a framework.

## 2. Dials (per design-taste-frontend Section 1)

| Dial | Value | Reason |
|---|---|---|
| `DESIGN_VARIANCE` | 6 | Offset, not symmetric. Studio-style layout — left-aligned headlines, generous gutters. Not art-gallery asymmetry (would feel performative for a learning center). |
| `MOTION_INTENSITY` | 4 | Restrained. Page-load fade-ins on hero + CRO engine; CTA hover lift. No scroll hijack, no parallax. Reduced-motion respected everywhere. |
| `VISUAL_DENSITY` | 4 | Daily-app spacing (`py-16` to `py-24` equivalent). Not airy gallery, not packed dashboard. |

**Rejected dial values:**

- VARIANCE at 9: would feel performative-craftsman for a 6-month drawing course. Studio means calm.
- MOTION at 7+: scroll-driven animation would distract from the CRO engine's primary job (get the prospect to type a WhatsApp message).
- DENSITY at 2: hero would float halfway down the viewport, copy would lose weight.

## 3. Design System

### Palette

- **Accent:** `#1a2332` (deep ink navy — primary CTA, hero headline, link underline)
- **Neutral background:** `#faf7f1` (warm white, slightly off to reduce eye fatigue during long reading)
- **Surface elevated:** `#ffffff` (cards, forms)
- **Neutral text:** `#1a2332` (same as accent — single ink color for hierarchy)
- **Muted text:** `#5a5a52` (body copy, captions)
- **Hairline:** `#e6e2d8` (dividers, card borders)
- **Mode:** Light only (single-theme lock per design-taste-frontend §4.11). The brand identity is light; a dark section sandwiched in would break the studio feel.

**Rejected palettes:**

- **Pure black `#000000` + pure white `#fff`:** kills depth. Banned per design-taste-frontend §9.A.
- **Beige `#f5f1ea` + brass `#b08947` + espresso `#1a1714`:** AI-default premium-consumer palette, banned per design-taste-frontend §4.2. Would also mis-signal luxury craft over structured learning.
- **Vibrant purple / teal accent:** would scream "AI startup", wrong for a 6-month drawing course.

### Typography

- **Display:** DM Serif Display (weights: 400). Used for h1, h2, hero. Self-hosted via `@font-face` + `font-display: swap`.
- **Body:** Inter (weights: 400, 500, 600). Self-hosted via `@font-face` + `font-display: swap`.
- **Mono:** `ui-monospace, SFMono-Regular, Menlo, monospace` — used only for numeric data (Lighthouse scores, commit counts).
- **Source:** Google Fonts download via curl, self-hosted under `/assets/fonts/`. Never linked via `<link>` in production per design-taste-frontend §3.A.

**Rejected font pairs:**

- **Fraunces + Inter:** Fraunces is banned as a default per design-taste-frontend §4.1. The coach template defaults to it, so I override.
- **Instrument Serif + Inter:** Instrument Serif is also banned per §4.1.
- **Playfair Display + Inter:** overused for editorial. Would feel fashion-magazine, not studio.

### Radius

- **Scale:** all-soft
- **Values:** `8px` (inputs, small cards), `16px` (service cards, content blocks), `999px` (buttons, pills). Single system.

### Grid

- **Base:** 8px
- **Container:** `max-width: 1120px` (matches industry-playbook `coach` default)
- **Breakpoints:** `sm 640`, `md 768`, `lg 1024`, `xl 1280`

### Motion

- **Type:** CSS transitions + entry fades only. No GSAP, no scroll-hijack.
- **Reduced-motion:** `@media (prefers-reduced-motion: reduce)` disables all entry fades and hover lifts. Hover states still get color/background change (instant), no transform.

## 4. The Honest Content Policy (per references/tone-of-voice.md)

This site ships with **deliberately empty slots** rather than fabricated content. Pre-flight hard-fails on fabrication (gate 1).

- **Reviews:** GBP shows **0 reviews, no rating**. Reviews page renders the honest count (0) with a "Be the first" CTA deep-linking to Google write-a-review. NO fabricated quotes.
- **Hours:** Not published on GBP ("Add business hours" still prompted). Every hours slot renders "Confirm by WhatsApp". NO invented "Mon-Sat 10am-8pm".
- **Prices:** Not published. Services page lists offerings with "Confirm by WhatsApp" pricing. NO invented ₹₹₹.
- **Photos:** 0 source images. Hero + cards use `picsum.photos/seed/<descriptive-seed>/<w>/<h>` placeholders. Every `<img>` has `onerror` swap to `/assets/monogram.svg`. Owner can drop real photos into `/assets/photos/` and update paths in `content/data.json`.
- **CTA labels:** Per-intent, never duplicated. "WhatsApp us" appears once per page (hero). "See the full course list" once (services). "Read the Google reviews" once (reviews).

## 5. The CRO Engine

**Engine type:** `quote-builder` (per `assets/industry-playbooks.json` for `coach`)

**Why quote-builder and not service-picker:** TGC's two known offerings (6-month drawing course + "Mind/Art/Music/Expression" practice) are too few and too varied for service-picker. Quote-builder is the universal fallback that fits "tell us what you want to learn, we'll tell you if we're a fit".

**Data source:** `content/data.json` — single file the owner edits to update copy without touching HTML.

**State transitions (4-question scope → WhatsApp pre-fill):**

1. **Q1 — What do you want to learn?** (drawing / visual art / music / expression / other)
2. **Q2 — Where are you now?** (complete beginner / some practice / returning after a break / intermediate)
3. **Q3 — What's your goal?** (personal practice / portfolio / career change / healing / explore)
4. **Q4 — When do you want to start?** (this month / next 3 months / just exploring)
5. **Submit → WhatsApp link with pre-filled scope message**

**WhatsApp pre-fill format:**

```
Hi — found The Groundwork Collective online.

I'd like to discuss:
- I want to learn: {answer_1}
- Where I am: {answer_2}
- My goal: {answer_3}
- I'd like to start: {answer_4}

Could we set up a discovery call?
```

**Where the engine lives:**

- Home page: yes (above the fold: yes — within the first 1.5 scrolls)
- Services page: no (services page is the deep-dive; CRO engine on home is the funnel)

## 7. The Pre-Flight Gates

Every gate is a hard fail:

- [ ] Gate 1: No fabricated content (reviews, hours, prices, photos)
- [ ] Gate 2: No dead buttons (every CTA resolves via link_probe.py)
- [ ] Gate 3: No placeholders visible (`{{TOKEN}}`, "Coming soon", "Lorem ipsum")
- [ ] Gate 4: No em-dashes (`—`) anywhere on the page — banned by design-taste-frontend §9.G
- [ ] Gate 5: Lighthouse ≥95 on all 4 axes (mobile)
- [ ] Gate 6: CRO engine works end-to-end (cro_test.py state-transition verification)
- [ ] Gate 7: Real photos with onerror fallback (picsum.photos + monogram)
- [ ] Gate 8: `prefers-reduced-motion` honored
- [ ] Gate 9: `prefers-color-scheme` respected (light-only here, but no flash-of-dark on reload)
- [ ] Gate 10: One accent (`#1a2332`), one font pair (DM Serif Display + Inter), one radius (soft: 8/16/999)
- [ ] Gate 11: WCAG AA contrast on all text (verified: `#1a2332` on `#faf7f1` = 14.7:1)
- [ ] Gate 12: Alt text on every meaningful image
